# Electricity Bill Calculator

A Python-based electricity bill calculator that calculates electricity charges based on unit consumption.

## Features
- Calculates electricity bills using tariff slabs.
- Tracks previous and current meter readings.
- Saves meter readings using file handling.
- Input validation.
- Error handling.

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Run `EBillCall.py`.
3. Enter your electricity meter reading.
4. Follow the instructions.
